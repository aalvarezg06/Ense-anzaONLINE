# Teoría: Diagramas de Clases

El diagrama de clases es la piedra angular del diseño orientado a objetos.

## Elementos del diagrama
- **Clase**: Atributos (estado) y Métodos (comportamiento).
- **Visibilidad**: Public (+), Private (-), Protected (#).

## Relaciones
- **Asociación**: Conexión general entre clases.
- **Agregación/Composición**: Relaciones de "todo-parte".
- **Herencia (Generalización)**: Relación "es un".
- **Realización**: Implementación de interfaces.
