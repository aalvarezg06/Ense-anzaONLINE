# Tutorial: Gestión Ágil con Kanban

En este tutorial aprenderás a organizar las tareas de un equipo de desarrollo.

## Objetivos
1. Crear un tablero Kanban.
2. Definir columnas de flujo (To Do, Doing, Testing, Done).
3. Gestionar el WIP (Work In Progress).

## Prerrequisitos
- Cuenta en Trello o acceso a GitHub Projects.
- Definición de un pequeño proyecto de software.
