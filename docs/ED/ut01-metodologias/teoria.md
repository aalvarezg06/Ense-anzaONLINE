# Teoría: Metodologías de Desarrollo

En esta unidad exploraremos cómo se construye el software de manera profesional.

## Contenidos principales
- **Ciclo de Vida del Software (SDLC)**: Planificación, Análisis, Diseño, Implementación, Pruebas y Mantenimiento.
- **Modelo en Cascada**: El enfoque tradicional secuencial.
- **Metodologías Ágiles**: Scrum, Kanban y el Manifiesto Ágil.
- **Comparativa**: Cuándo usar cada enfoque según el proyecto.
