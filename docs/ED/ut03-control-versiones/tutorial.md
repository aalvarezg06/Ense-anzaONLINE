# Tutorial: Primeros Pasos con Git

Aprende los comandos que usarás a diario.

## Workflow básico
```bash title="Terminal"
# Inicializar repositorio
git init

# Añadir archivos al área de preparación
git add .

# Guardar cambios localmente
git commit -m "Mensaje descriptivo"

# Subir al servidor (GitHub)
git push origin main
```

## Gestión de ramas
```bash title="Ramas"
# Crear una nueva rama
git checkout -b feature/nueva-web

# Listar ramas
git branch
```
