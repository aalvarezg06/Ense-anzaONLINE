# Teoría: Fundamentos de Git

Git es la herramienta estándar para el seguimiento de cambios en el desarrollo de software.

## Conceptos clave
- **Repositorio**: Almacén donde se guarda el código y su historial.
- **Commit**: Instantánea de los cambios realizados.
- **Rama (Branch)**: Línea de desarrollo independiente.
- **Merge**: Fusión de cambios entre ramas.

## Flujos de trabajo
- **Centralizado**: Todos trabajan sobre una única rama.
- **Feature Branch**: Cada funcionalidad se desarrolla en una rama aparte.
- **GitFlow**: Un modelo robusto para proyectos grandes.
