# Teoría: Diagramas de Comportamiento

Mientras que los diagramas de clases muestran la estructura, estos muestran cómo "vive" el sistema.

## Diagramas de Casos de Uso
- **Actor**: Entidad externa que interactúa con el sistema.
- **Caso de Uso**: Funcionalidad o servicio que ofrece el sistema.
- **Relaciones**: Include, Extend y Generalización.

## Diagramas de Secuencia
- Muestran el intercambio de mensajes entre objetos a lo largo del tiempo.
- **Líneas de vida**: Representan la existencia del objeto.
- **Mensajes**: Síncronos, asíncronos y de retorno.
