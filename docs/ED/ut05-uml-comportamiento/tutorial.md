# Tutorial: Diagramas de Casos de Uso

Aprende a capturar lo que el usuario espera del sistema.

## Pasos para el diseño
1. **Identificar Actores**: ¿Quién usa el sistema? (Admin, Usuario, Sistema Externo).
2. **Definir Casos de Uso**: ¿Qué acciones realizan? (Login, Comprar, Gestionar Inventario).
3. **Establecer Límites**: Dibujar el recuadro del sistema.
4. **Conectar**: Unir actores con casos de uso mediante asociaciones.

## Ejemplo práctico
Diseño de un sistema de gestión de biblioteca donde un Bibliotecario puede prestar libros y un Socio puede buscarlos.
