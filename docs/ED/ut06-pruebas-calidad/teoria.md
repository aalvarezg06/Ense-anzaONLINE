# Teoría: Calidad del Software y Pruebas

El desarrollo no termina cuando el código compila; termina cuando es robusto y mantenible.

## Pruebas Unitarias (Unit Testing)
- **Definición**: Pruebas que validan la unidad más pequeña de código (un método).
- **JUnit**: El framework estándar para Java.
- **Aserciones**: `assertEquals`, `assertTrue`, `assertNotNull`.

## Documentación con Javadoc
- Uso de etiquetas como `@param`, `@return`, `@throws`.
- Generación de HTML para consulta técnica.

## Refactorización
- Modificar el código interno sin cambiar su comportamiento externo.
- **Clean Code**: Nombres descriptivos, métodos cortos y responsabilidad única.
