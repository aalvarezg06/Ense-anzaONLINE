# Tutorial: Configuración de IntelliJ IDEA

Aprende a preparar tu herramienta principal de trabajo.

## Pasos principales
1. **Descarga**: Obtener la versión *Community Edition* de la web de JetBrains.
2. **Instalación**: Seguir el asistente y configurar el JDK.
3. **Primer Proyecto**: Crear un proyecto Java con Maven.
4. **Plugins**: Instalar extensiones útiles (Key Promoter X, Lombok).

## Atajos de teclado esenciales
- `Shift + Shift`: Buscar en todo el proyecto.
- `Alt + Enter`: Sugerencias y correcciones automáticas.
- `Ctrl + D`: Duplicar línea.
