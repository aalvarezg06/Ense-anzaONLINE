# Introducción a Acceso a Datos

Bienvenido al módulo de **Acceso a Datos**. En esta sección exploraremos las diferentes tecnologías y metodologías para interactuar con sistemas de almacenamiento de información desde aplicaciones Java y otros lenguajes.

## ¿Qué es el Acceso a Datos?

El acceso a datos es la parte de la ingeniería de software que se encarga de la persistencia de la información. Consiste en la capacidad de una aplicación para recuperar, modificar y almacenar datos en diferentes soportes físicos o lógicos.

## Objetivos del Módulo

A lo largo de este curso, aprenderemos a:

- **Manejo de ficheros:** Lectura y escritura de archivos de texto, binarios y XML.
- **Bases de Datos Relacionales:** Uso de SQL y conectividad mediante **JDBC**.
- **Mapeo Objeto-Relacional (ORM):** Implementación de persistencia con frameworks como **Hibernate**.
- **Bases de Datos NoSQL:** Exploración de alternativas como MongoDB o bases de datos orientadas a objetos.
- **Componentes de Acceso a Datos:** Creación de DAOs (Data Access Objects) y capas de servicio.

## Herramientas Principales

Para el desarrollo de las prácticas utilizaremos:
- **IDE:** IntelliJ IDEA o Eclipse.
- **Gestores de BD:** MySQL, PostgreSQL o MariaDB.
- **Build Tools:** Maven o Gradle para la gestión de dependencias.

---

> [!TIP]
> Recuerda que una buena capa de acceso a datos debe ser independiente de la lógica de negocio para facilitar el mantenimiento y la escalabilidad.
