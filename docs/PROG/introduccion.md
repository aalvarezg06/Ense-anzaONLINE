El módulo de **Programación (PROG)** es el pilar fundamental de cualquier desarrollador de software. A lo largo de este curso, nos centraremos en dominar el lenguaje **Java** y los principios de la **Programación Orientada a Objetos (POO)**.

## ¿Qué aprenderás?

1.  **Lógica Algorítmica**: Cómo descomponer problemas complejos en pasos sencillos.
2.  **POO**: El paradigma dominante en la industria para crear sistemas escalables.
3.  **Gestión de Datos**: Uso de colecciones, estructuras dinámicas y persistencia en ficheros.
4.  **Calidad de Código**: Escritura de código limpio, documentado y fácil de mantener.

## Stack Tecnológico

-   **Lenguaje**: Java 21 (LTS).
-   **IDE**: IntelliJ IDEA Community Edition.
-   **Documentación**: Javadoc.

> [!TIP]
> La programación no se aprende leyendo, se aprende picando código. Te animamos a que repliques cada ejemplo y realices todos los retos propuestos.
