La información en memoria es volátil. Aprenderemos a guardarla y recuperarla usando el sistema de archivos.

## Contenidos
- **Clase File**: Gestión de rutas, directorios y metadatos.
- **Flujos de Texto**: `FileReader`, `FileWriter` y `BufferedReader`.
- **Serialización**: Guardando objetos completos en archivos binarios.
- **NIO.2**: Uso de la API moderna de archivos en Java.
